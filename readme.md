# 🏦 Banco SENAC

## 📌 Sobre o projeto

O **Banco SENAC** é um projeto acadêmico desenvolvido para simular um sistema bancário simples, permitindo que os usuários acessem sua conta e realizem operações financeiras básicas por meio de uma interface web.

## 🚀 Funcionalidades

- **Login:** acesso à conta utilizando os dados cadastrados.
- **Registro:** cadastro de novos usuários.
- **Saque:** retirada de valores do saldo disponível.
- **Depósito:** adição de valores ao saldo da conta.
- **Transferência:** envio de valores para outra conta.
- **Validação de dados:** verificação das informações inseridas pelo usuário.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura da aplicação.
- CSS3 — estilização e layout.
- JavaScript — interatividade, validações e lógica das operações.

## ▶️ Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` em um navegador.
4. Utilize a interface para testar as funcionalidades implementadas.

## 🎯 Objetivo

Praticar conceitos de desenvolvimento web, manipulação do DOM, eventos JavaScript, validação de formulários e lógica de programação por meio da construção de uma aplicação bancária simulada.

## ⚠️ Observação

Este projeto tem finalidade educacional. As funcionalidades serão implementadas gradualmente e não representa um sistema bancário real.
